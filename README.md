Dapur Kilat is a fast-paced burger-assembly cooking game: orders land on the board, you stack ingredients on the plate, and you serve before the customer walks away. One 90-second shift, three hearts, and a kitchen that only gets busier.

## Run it

```sh
python3 -m http.server --directory game 8080
```

Then open http://localhost:8080. Click an ingredient (or press 1–6) to stack it on the plate, press Space to serve when the stack matches an order, C to clear the plate.
